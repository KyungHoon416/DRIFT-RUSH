## HUD 배치·터치 기준

- 기본 카메라: 카트 뒤에서 약간 높이, 도로 중앙을 보게 함. 기울기 조향은 HUD 터치와 독립적으로 작동.
- 좌상단 순위: `2nd / 8` 크게, 실시간 전체 순위표는 펼침/축소 지원.
- 상단 중앙: `LAP 2/3`, 타이머, 베스트랩.
- 우상단: 미니맵, 본인 위치, 설정 버튼.
- 좌하단: BRAKE 버튼(누르는 동안 감속), 아이템전은 선택 아이템 슬롯.
- 중앙 하단: 현재 속도(`128 km/h` 형식의 예시 UI), 부스터 충전 표시.
- 우하단: 큰 DRIFT, 작은 BOOST. 버튼은 영역 충돌을 막을 만큼 충분한 간격.
- 각 오버레이는 `CanvasLayer`와 `Control` 앵커를 사용하여 노치/제스처 바/화면비 차이에 대응.
- 플레이어 카트 주변을 가리지 않도록 좌우 가장자리에 HUD 밀집, 중앙에는 주행 시야 확보.

## 디자인 주의

콘셉트 이미지의 `Sakura Valley` 풍차/폭포/다리는 독자적인 트랙 장식으로 재구성할 것. 작은 UI 텍스트나 모델 이미지를 그대로 잘라서 클릭 가능한 UI라고 속이지 않는다. 모든 버튼은 실제 Godot 씬에서 신호·상태에 연결돼야 한다. 무료/상업용 에셋을 사용할 때 라이선스 확인.
